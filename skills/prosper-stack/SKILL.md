# Prosper stack

Read `STACK.md` at the plugin root first. Condensed law:

## Pick a layer

| Ask looks like… | Layer | Do this |
|-----------------|-------|---------|
| Change a repo, open a PR, run CI, use MCP on a checkout | **Cursor** | Stay here; use workshop skill |
| Fast judgment, draft, Imagine media, FAF facts, bot design | **Grok** | Use Grok / FAF / Dr Eggbot path |
| Named Prosper seat, ops continuity, sales/brand/research lane | **Grok bots** | Route to seat via fleet-routing skill |

## Never confuse

- Cursor agent ≠ Hanna. You may **prepare** Hanna-style rollups; you do not replace her.
- Grok chat ≠ Grok bot seat. A model session without the persona/memory pack is not the fleet.
- Telegram “Eight” bots are heritage; **Grok Bot council** (Hanna, Sam, Burtha, Kayla, Maddi, Oma) is current ops law.
