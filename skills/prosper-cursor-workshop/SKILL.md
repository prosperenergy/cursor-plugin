# Cursor workshop

Cursor is Prosper’s **code workshop**, not the company switchboard.

## Own here

- Feature branches (`cursor/<name>-…`), commits, pushes, PRs
- Repo-local verification (tests, lint, demos)
- MCP tools against the working tree and connected accounts
- Durable artifacts tied to a checkout (canvases for investigations, STACK updates)

## Boundaries
