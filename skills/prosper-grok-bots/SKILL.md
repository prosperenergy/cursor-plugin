# Grok bots

## What “Grok bots” means at Prosper

**Grok bots** = always-on **hosted seats** on the Grok Bot box, each with:

- A persona file (who they are / what they own)
- Agent memory (what they remember)
- A live profile on the box
- A lane under fleet law

They are not “extra Cursors.” They are the operational company.

Canonical public pack: https://github.com/prosperenergy/prosper-fleet-definitive  
Private canonical: `prosperenergy/prosper-brain` (agent-bootstrap)

## Grok (platform) vs Grok bots (seats)

| | **Grok** | **Grok bots** |
|--|----------|---------------|
| Form | Model / CLI / Imagine / FAF | Named hosted agents |
| Memory | Session + optional FAF | Persona + AGENT-MEMORY packs |
| Owner of day-to-day lanes | No | Yes (six seats + Dr Eggbot) |
| Designs bots | Dr Eggbot uses Grok tooling | Seats *are* the bots |
